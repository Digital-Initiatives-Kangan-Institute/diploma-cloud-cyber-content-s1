## 4. Notes / decisions
- **Monday-only cluster, 8 weeks.** Two 3h sessions each Monday (9am-12pm, 1pm-4pm) from 5 Oct, the
  last on 23 Nov — four days before CL2 finishes, because a Monday-only cluster runs out of the window
  earlier. No Victorian public holiday falls on a Monday in the window (Melbourne Cup is Tue 3 Nov).
- **16 sessions against a nominal 20** — this intake is 4 short of the frame. Reported by the gate as
  an instance allocation, not an error.
- **No onboarding session.** Mid-semester start with a cohort already onboarded in CL1; the frame was
  amended accordingly (2026-09-09).
- **Three teach-then-assess blocks, in order:** T1-T4 → AT1 · T5-T6 → AT2 · T7-T8 → AT3.
- **AT2 gets four sessions because the assessment requires it.** Every student must be observed leading
  one team meeting. With teams of four and two teams running, the assessor takes two observations per
  session, so four sessions covers the cohort. Each session is a meeting followed by the allocated
  component build — the allocation has to be consequential for the meeting to be a real meeting.
- **AT2 and AT3 are sequential.** AT2's product is the team's integrated implementation; AT3 is the
  individual implementation that follows. They cannot share a session.
- **CL3 carries NO in-term contingency** — the work fills every session exactly. If it overruns, the
  reserve is CL2's three spare sessions (26-27 Nov, same cohort) or the emergency contingency weeks
  after the nominated finish. Which is drawn on first is a live-delivery call.
